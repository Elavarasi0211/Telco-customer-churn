# Telco Customer Churn Analysis

## Project Overview

This project analyzes Telco Customer Churn data using Python and Tableau. The main objective of this project is to understand customer behavior, identify churn patterns, and generate meaningful business insights using data analytics and visualization techniques.

Customer churn is one of the biggest challenges faced by telecommunication companies. By analyzing customer data, businesses can improve customer retention strategies and reduce customer loss.


## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Tableau
* Jupyter Notebook


## Dataset

Dataset Used:
Telco Customer Churn Dataset from Kaggle

### Dataset Features

* Customer ID
* Gender
* Senior Citizen
* Partner
* Dependents
* Tenure
* Phone Service
* Internet Service
* Contract Type
* Payment Method
* Monthly Charges
* Total Charges
* Churn

## Key Insights

* Customers with month-to-month contracts showed higher churn rates.
* Customers with higher monthly charges were more likely to churn.
* Long-term customers were less likely to leave the service.
* Fiber optic internet users showed higher churn behavior.


## Business Recommendations

* Improve customer retention strategies
* Provide better customer support
* Encourage long-term contract plans
* Monitor customer churn regularly using dashboards


## Conclusion

This project demonstrates how Data Analytics and Visualization tools can transform raw customer data into meaningful insights and business decisions using Python and Tableau.
